# Меморандум №1 (сжато): ревью трёх исходных веток + первый флагман

## Вердикты по трём исходным веткам

### 1. Coverage-Twilight Pre-Earnings — УБИТА как флагман
- Убийца: backtest невозможен без PIT-истории consensus, которой нет и которую
  нельзя купить в бюджете; бесплатные Yahoo/FMP-числа за прошлое = пересмотренные
  (look-ahead). Первый результат только через 4–6 кварталов живого сбора.
- Второй убийца: лицензии. Consensus у Yahoo/FMP — перепроданный, ToS запрещают
  систематический сбор и перераспространение → главный планируемый актив
  (PIT-база) юридически непоказуем.
- Сохранить: Forecastability/NO TRADE, immutable journal, методологию.

### 2. AI Reader Distortion / Model Monoculture — УБИТА как alpha
- Цепочка из 5 звеньев перемножается в ~2–5%; звено «рынок последовал машинному
  прочтению» принципиально неидентифицируемо (не видно, кто читал LLM-ом).
- Частота враждебного форматирования в EDGAR ≈ 0.
- База в литературе: Cao–Jiang–Yang–Zhang, RFS 2023 «How to Talk When a Machine
  Is Listening» — обратный эффект машинного читателя на раскрытие уже опубликован.
- Сохранить: benchmark детектора скрытого/враждебного форматирования (2–3 недели,
  publishable) + risk-инструмент. НЕ смешивать с alpha.

### 3. Regulatory Normalization Lag (ASU 2023-07/09, 2024-03) — УБИТА как флагман
- Методологический дефект, который никто не заметил раньше: все компании принимают
  стандарт одновременно → нет кросс-секции по времени лечения → «эффект стандарта»
  неотделим от календарного времени. Вариация только по сложности раскрытия,
  а она эндогенна размеру/отрасли/менеджменту.
- ASU 2023-09 = одна годовая волна к авг-2026; ASU 2024-03 = массив только к 2028.
- Сохранить: disclosure-complexity и custom-tag ratio как features.

### Regime-Aware Pre-Earnings Engine (агрегат) — НЕ СТРОИТЬ
Наследует болезнь ветки 1 + два ослабленных модуля.

## Первый флагман мемо №1: Cross-Lender Mark Convergence (позже → ShadowNAV)
Механизм: BDC оценивают один и тот же заём по-разному (PIMCO: разрыв
оптимист-консерватор >5 п.п. по общим займам); lead-кредиторы ставят выше
(информационная асимметрия). H1: марка-выброс предсказывает переоценку
отстающего в t+1.
- Данные: EDGAR SOI, бесплатно, PIT по acceptance datetime, лицензии чистые
- Ground truth бухгалтерский (марка следующего квартала), не returns
- Формула: Δ(i,j,t)=FV(i,j,t)−median_k FV(i,k,t); IM(j,t)=Σ w·max(0,Δ)
- Baselines: персистентность, momentum, non-accrual флаг, discount-to-NAV
- Издержки: шорт BDC = дивиденд 10–12% годовых → ТОЛЬКО relative value
- Look-ahead риск №1: использовать period_end вместо acceptance datetime
- Power: стадия марок — высокая; стадия equity (~50 тикеров × 28 кв.) — заведомо
  underpowered, объявлять вспомогательной
- Vendor-контекст: описательный слой коммодитизирован (Moody's, PIMCO, ФРБ
  Бостона, Cliffwater CDLI ~21k займов $549B) — признавать прямо
- Kill criteria: парсинг <90% на 200 строках; <150 пар общих заёмщиков на 15 BDC;
  β≈0; конвергенция объясняется entry price

## Уроки мемо №1
1. PIT-consensus-коллектор был ловушкой (критический путь, а не модуль)
2. Sweet spot $500M–$5B недоказан и с двойным штрафом по данным/издержкам
3. «Не нашли статьи» ≠ новизна — правило записали, но не применяли
4. Регуляторные идеи проверять по статусу ДО проектирования (Form SHO мертва до 2028)
5. «8 агентов» = список ролей; реально LLM нужен в 2–3 местах, остальное ETL
