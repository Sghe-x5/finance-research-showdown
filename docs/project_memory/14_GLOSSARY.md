# Glossary

- **BDC** — Business Development Company, a regulated investment company often lending to private middle-market firms.
- **SOI** — Schedule of Investments.
- **NAV** — net asset value.
- **NII** — net investment income.
- **PIK** — payment-in-kind interest.
- **Non-accrual** — loan no longer accruing interest income normally.
- **Economic facility** — one borrower/tranche/lien/type/currency/rate/maturity/funded-status exposure after aggregating reporting lots.
- **Source** — BDC whose current-quarter facility mark became public first.
- **Target** — later-reporting listed BDC holding the same facility.
- **Persistence baseline (B0)** — target current mark predicted as its prior mark.
- **Source-delta transfer** — target prior mark plus source mark change.
- **Cross-manager** — source and target managed by different asset-management organizations.
- **Development period** — period used to formulate/fix the hypothesis; excluded from confirmatory testing.
- **Outcome-blind** — selection/review data excludes protected target-current numeric outcomes.
- **Structural reveal** — target-current non-numeric facility structure revealed before marks.
- **Numeric reveal** — marks/fair values revealed only after structural consensus freeze.
- **Abstention** — matcher/reviewer returns uncertain instead of forcing a class.
