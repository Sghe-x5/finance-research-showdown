# Repository Recovery Checklist for a New Session

1. Open the repository and identify the latest active branch/commit.
2. Read `PROJECT_MEMORY_START_HERE.md`.
3. Read the newest dated memory snapshot.
4. Read current canonical files under `docs/research/`.
5. Compare the memory current-state date with repository commit dates.
6. Check `INTEGRATION_NOTES.md` for unresolved inconsistencies.
7. Do not access `private/`.
8. State back:
   - current flagship;
   - current stage;
   - last valid result;
   - invalidated results;
   - next protected boundary.
9. Only then propose or execute work.
