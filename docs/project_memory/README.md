# Finance Research Project — Persistent Memory Pack

This folder is a durable, human-readable reconstruction of the **visible** research,
decisions, critiques, failed hypotheses, sources, and current state of the project.

It exists for three reasons:

1. A new ChatGPT/Claude chat can recover the project without repeating weeks of research.
2. Codex can distinguish current canonical conclusions from old exploratory ideas.
3. Every important reversal, invalidated result, and methodological guard remains auditable.

## Important boundary

This archive contains:
- visible messages and explicit research summaries;
- public sources and links;
- decisions, assumptions, tests, and open questions;
- repository/commit references.

It does **not** contain:
- private keys or hidden blind mappings;
- secrets, API keys, credentials, or personal SEC User-Agent email;
- hidden model chain-of-thought;
- target outcomes that remain protected by the research protocol.
