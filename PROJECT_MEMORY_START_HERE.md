## Authority and safety boundary

Project memory preserves visible conclusions, invalidated claims, sources,
decision history, and handoff context. Dated memory does not override newer
canonical research artifacts. When they differ, record the difference instead
of silently rewriting history.

The memory folder must never contain private reviewer mappings, secrets, API
keys, protected outcome keys, protected target-current outcomes, raw licensed
vendor data, personal SEC contact details, or hidden model chain-of-thought.
